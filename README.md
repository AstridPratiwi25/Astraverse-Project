# ASTRAVERSE — Astrid's Dream Universe

A dreamy interactive 3D universe built with HTML, CSS, JavaScript, and Three.js.

## Run locally

Because this project uses JavaScript ES modules, run it through a local web server (not by double-clicking `index.html`).

### Option 1 — VS Code
1. Open this `ASTRAVERSE` folder in VS Code.
2. Start the project with the Live Server extension.
3. Open the local URL shown by Live Server.

### Option 2 — Python
From this folder, run:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Project structure

```text
ASTRAVERSE/
├── index.html
├── README.md
├── css/
│   └── style.css
├── js/
│   ├── main.js
│   ├── soundtrack.js
│   └── effects.js
└── assets/
    ├── images/
    └── audio/
```

- `index.html`: page structure and Three.js import map.
- `css/style.css`: visual styling and animations.
- `js/main.js`: Three.js scene, planets, galaxy journey, navigation, and crystal mini-game.
- `js/soundtrack.js`: procedural ambient soundtrack and music controls.
- `js/effects.js`: click sparkles, cursor trail, and Escape-key navigation.
- `assets/`: place future external image, audio, and font files here.

## Notes

- Three.js is loaded from the CDN via the import map in `index.html`.
- The original V5.1 embedded logo/favicon and existing visual assets are preserved.
- The procedural soundtrack is generated by the browser using Web Audio API; it is not an external MP3.
